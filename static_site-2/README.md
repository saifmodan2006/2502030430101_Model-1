A stunning, modern 3D animated website built with pure HTML, CSS, and JavaScript. This project showcases cutting-edge web design techniques and advanced interactivity.

### Design Excellence
- **Modern Aesthetics**: Clean, minimalist design with elegant flourishes

- **3D Rendering**: Three.js-based particle system for immersive backgrounds

## 🛠️ Customization

### Changing Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #8B5CF6;
    --secondary-color: #EC4899;
    /* ... */
}
```

### Adjusting Animations
Modify animation durations and delays in `style.css`:
```css
@keyframes fadeInUp {
    from {
        transform: translateY(50px);
        opacity: 0;
    }
    to {
        transform: translateY(0);
        opacity: 1;
    }
}
```

### Customizing Content
Edit text and content directly in `index.html`:
- Update section titles and descriptions
- Modify card content and icons
- Change form placeholders
- Update navigation links
