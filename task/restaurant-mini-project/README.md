# Restaurant Mini Project

This folder contains the cleaned, task-wise Bootstrap restaurant website.

## Task Order
1. Basic HTML structure
2. Restaurant header
3. Responsive navbar
4. Hero section
5. Food menu cards
6. Responsive grid layout
7. Services section
8. Image gallery
9. Customer review section
10. Contact form
11. Footer
12. Full responsiveness
13. Bootstrap modal
14. Carousel slider
15. Final combined website

## Files
- `index.html` - full restaurant website
- `assets/css/style.css` - custom styling
- `assets/js/script.js` - small behavior script
- `bootstrap-classes.txt` - Bootstrap class reference by section

## How to Run
Open `index.html` in a browser.
